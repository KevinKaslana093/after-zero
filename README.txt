《零点之后》 AFTER ZERO
都市怪谈 × 深夜电台 · 男性向视觉小说 V4.6

身份设定
- 男主角固定名为江临；玩家以屏幕外的“回答者”身份输入自己的名字。
- 玩家姓名不会替换男主姓名，只会在系统外对话与真结局回收。
- 五条个人线会分别留下耳机、照片、声纹、病历和姓名异常，最终共同证明玩家存在。
- 真结局中，江朔会越过江临直接与玩家对话，并启动永远停在 00:13 的零点世界。
- 完整终局包含江临被删除、五位女主进入被覆盖时间线之海、玩家回答江临，以及江朔一条路走到黑的最终对决。

运行方法
1. 双击 index.html。
2. 推荐使用最新版 Chrome 或 Edge，分辨率 1280×720 以上。
3. 游戏完全离线运行；第一次点击后才会启用浏览器音效。

操作
- 鼠标左键 / Enter / 空格：继续对话
- A：自动播放
- S：跳过已读
- Esc：游戏菜单
- 游戏内含自动存档、6 个手动存档、剧情回看、设置与结局档案。
- 各场景使用程序化原创动态配乐与空间声景；总音量、背景音乐、剧情音效可分别调节或静音。

路线机制
- 开局不会直接选择女主。
- 共通线的三组选择会累积角色信号（好感）。
- 第二章结束后，系统会按最高信号自动进入个人线，不再弹出女主选择菜单。
- 信号同分时，以玩家最近一次明确关注的对象作为路线判定。
- 每条个人线包含调查、日常、危机和关系收束；个人线选择继续影响信号值。
- 通关一条路线后，会回到共通线选择阶段；已读跳过可用于快速尝试其他答案。
- 收集五位女主结局后，第六频道 TRUE SIGNAL 会在分歧点自动插入一次。

五位女主（均为成年人）
- 林澄，27 岁：克制冷静的深夜主持人。
- 唐砂，22 岁：娇小活泼的街头摄影师；日常服为防水短外套、实用短裤与光腿运动鞋造型。
- 苏弥，25 岁：困倦寡言的声音工程师。
- 顾晚晴，31 岁：眯眯眼的急诊医生与成熟姐姐型角色。
- 纪遥，24 岁：睁眼、戴眼镜的民俗档案研究员。
